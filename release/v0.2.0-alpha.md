# Pennovia v0.2.0 (alpha)

First tagged GitHub release. Python Core, CLI and local Studio share one author-voice analysis, drafting, review and export pipeline.

**Included:** HTTPS links, pasted writing and TXT/HTML/PDF samples; portable voice-profile JSON; configured Ollama/OpenAI/Anthropic/OpenRouter/Codex drafting; heuristic style review; browser editing; TXT/HTML/PDF, Google Drive and draft-only Studio WordPress exports.

**Verified:** Python 3.10–3.12 CI, wheel/container smoke tests, Chromium desktop/mobile flow, and a live local Ollama `qwen2.5:1.5b` run on authentic chapters of Mark Twain's *The Innocents Abroad* (Project Gutenberg #3176). The live run keeps one chapter out of training, generates two styled drafts plus a neutral control, and records model digest, source hash, heuristic scores and export artifacts.

**Limits:** The style scores are uncalibrated. The small-model trial demonstrates real inference and inspectable outputs, **not** proven author-voice fidelity, authorship identification or verified factual accuracy. No live WordPress/Google Drive publishing was performed. The browser Studio runs on the user's computer, not a hosted service. No PyPI publication is claimed.

**Install:** Download the release wheel or source archive below, or clone the tagged commit. Run `pennovia studio` after installation.

**Source:** https://www.gutenberg.org/ebooks/3176 (public-domain work, Project Gutenberg distribution terms apply).
