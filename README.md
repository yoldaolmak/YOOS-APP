# Pennovia

**Your voice. Your words.**

[![CI](https://github.com/yoldaolmak/Pennovia/actions/workflows/ci.yml/badge.svg)](https://github.com/yoldaolmak/Pennovia/actions/workflows/ci.yml) · Python 3.10+ · MIT · Open source

**Pennovia is an open-source author voice toolkit.** Give it writing you have permission to use, inspect how you write, and use that profile to guide an AI-assisted draft without surrendering editorial control.

It is a standalone Python CLI. No hosted account, subscription, proprietary runtime, or vendor-specific voice storage is required. Its statistical analysis runs locally; model inference can use Ollama or a configured external provider.

## What you can actually do

| Capability | Output |
| --- | --- |
| **Analyze** | Portable JSON profile of sentence rhythm, vocabulary, punctuation, paragraph patterns and recurring expressions |
| **Draft** | Text generated by an optional configured model using your profile and a content template |
| **Review** | Local, explainable heuristic observations about style alignment and common generic phrases |
| **Export** | TXT, HTML, PDF, optional Google Drive upload or WordPress draft |

**Release: 0.2.0 alpha.** Voice similarity numbers are *uncalibrated heuristics*, not evidence of identity, authorship, lived experience, factual correctness, or publication quality. A human must review generated work.

## Quick start

```bash
git clone https://github.com/yoldaolmak/Pennovia.git
cd Pennovia
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
pennovia --version
pennovia demo
python -m pytest -q
```

`pennovia demo` reads bundled public-domain sample excerpts. With no provider credentials it uses **clearly labeled mock text** to demonstrate the complete offline analyze → audit → export flow; it does not prove model-generation quality.

## Use your own writing

```bash
pennovia analyze --corpus ./my-articles --author "Example Writer" --out my-voice.json
pennovia generate --profile my-voice.json --type travel_guide --topic "Three days in Lisbon" --backend ollama --out draft.txt
pennovia export --input draft.txt --title "Lisbon guide" --format html --dest downloads
```

Available generation backends: Ollama, OpenAI, Anthropic, OpenRouter and Codex CLI. Ollama requires a running local service; cloud services require your own API key and may require `pip install -e ".[llm]"`. `--backend auto` may choose a configured cloud provider.

To create a WordPress **draft**, set `WP_URL`, `WP_USER` and `WP_APP_PASSWORD`, then choose `--dest wordpress`. The endpoint must use HTTPS. Publication requires an explicit `--publish`; nothing is published automatically by analysis or generation.

## Container

```bash
docker build -t pennovia .
docker run --rm pennovia --version
docker run --rm pennovia demo
```

Pennovia's image runs a command-line tool, not a web service. A container's generated output is ephemeral unless you mount a suitable volume.

## Data and trust boundaries

- Your source files are read locally. Generated voice profiles **may contain verbatim sample sentences** from your corpus. Store them accordingly.
- Cloud draft requests transmit selected prompt content, including representative source sentences, to the configured model provider.
- Optional WordPress and Google Drive exports make network requests only when invoked.
- Generated facts, quotations and first-person accounts can be incorrect or invented; review them before publishing.
- Use only writing you have rights or permission to process.
